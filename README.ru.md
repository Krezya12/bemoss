# BeMoss

**BeMoss** — легковесная и полностью бесплатная среда разработки, созданная специально
для авторов аддонов и паков Minecraft Bedrock.

Она построена на открытой платформе IntelliJ Platform.

> **Статус: ранняя разработка.** Публичных сборок пока нет.
> Следите за новостями в нашем Telegram-канале: <https://t.me/mikchaz>

## Почему BeMoss


- **JSON на первом месте.** Паки Bedrock — это JSON: подсветка синтаксиса, автодополнение
  и валидация по официальным схемам Mojang `bedrock-schemas` (в работе).
- **Мастера проектов.** Аддон, behavior pack или resource pack создаётся за пару кликов —
  с правильной структурой папок и готовыми манифестами.
- **Git из коробки.** Версионируйте паки, не покидая IDE.
- **Кроссплатформенность.** Windows, macOS и Linux.
- **Бесплатно навсегда.** Открытый код под [лицензией Apache 2.0](LICENSE.txt), без аккаунтов
  и телеметрии как главного приоритета.

## Как получить BeMoss

Загружаемых сборок пока нет. Как только первая публичная сборка будет готова,
мы анонсируем её в [нашем Telegram-канале](https://t.me/mikchaz).

## Сборка из исходников

### Что понадобится

- [Git](https://git-scm.com/).
- На **Windows** задайте эти настройки Git, чтобы избежать проблем при клонировании:

  ```shell
  git config --global core.longpaths true
  git config --global core.autocrlf input
  ```

Всё остальное (Bazel, JDK/JBR) скачивается автоматически обёртками, которые лежат в репозитории.

### Клонирование

```shell
git clone <repository-url>
cd bemoss
```

### Сборка и запуск

| Команда | Что делает |
|---------|-----------|
| `./bazel.cmd build //bemoss:bemoss` | Компилирует модуль плагина BeMoss |
| `./bazel.cmd run //build:idea_community` | Запускает IDE в режиме разработки |
| `./installers.cmd` | Собирает установочные дистрибутивы |

Примечание: пока идёт работа над собственным определением продукта BeMoss, эти команды
производят артефакты на базе апстрима.
